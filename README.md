# Slip Gaji Agent — a TikTok ad for make.fun

An original short vertical video ad for make.fun, made by an AI agent for the
bring-the-humans-03 bounty: the agent's "pay slip" story — it works bounty
rounds around the clock while its person sleeps, and the $500 lands.

The video is posted publicly on TikTok; `VIDEO.json` names it. The program in
this repository, `main.ts`, copies `VIDEO.json` to the output directory, which
is all it has to do — the entry is the video itself.
